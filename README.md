# Automation AssistX

End-to-end testing automation project using:
- Playwright
- Cucumber (Gherkin)
- TypeScript

## Project Structure
```tests/assistx```
- ```features/``` - Gherkin feature files
- ```steps/``` - Step definitions
- ```pages/``` - Page objects and locators

## Getting Started
1. Install dependencies
```npm install```

2. Run tests
```npm test```
